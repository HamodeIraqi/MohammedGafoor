## ✨ المميزات الرئيسية للموقع
- **تصميم سيادي وتنفيذي فاخر:** متوافق مع أعلى معايير الويب الرسمية (الهوية الكحلية والخمري مع اللمسات الذهبية الملكية).
- **باركود مدمج وسريع:** بطاقة باركود تفاعلية ورمز QR للطباعة على الوثائق الورقية.
- **تصدير وطباعة PDF فائقة الدقة:** تنسيق خاص بالطباعة يخفي أزرار التحكم ويظهر الباركود الرسمي في رأس الصفحة الورقية.
- **بطاقة الاتصال الرقمية (vCard):** زر مباشر لتنزيل جهة الاتصال الرسمية وإضافتها للهاتف بنقرة واحدة.
- **مشاركة سريعة:** دعم مشاركة الرابط عبر تطبيقات التواصل أو نسخه بضغطة زر.
- **استجابة كاملة:** متوافق مع كافة أحجام الشاشات (الهواتف الذكية، الأجهزة اللوحية، وشاشات سطح المكتب).
